标题：PR-1 开发文档：bounded_lite_model_config 参数透传与契约骨架
1. 背景与问题
- 当前 bounded_lite_model_config 在运行时被当作无参数调用。
- 现象：apply 调用后配置不变。
- 根因：tool schema/adapter 未正确声明并透传请求体。
2. 目标
- 允许结构化入参完整进入 handler。
- 对请求进行严格校验（missing/unknown action、unknown field）。
3. 非目标
- 不实现推荐算法细节。
- 不改模型池合并逻辑（放到 PR-2）。
4. 输入契约（强约束）
- action 必填：import|list|auto|apply
- 可选：
  - assignments: Record<string,string>
  - reasoningEffortAssignments: Record<string,"minimal"|"low"|"medium"|"high">
  - taskLeadProfileAssignments: Record<string,string>
- unknown top-level field：拒绝。
5. 实施步骤
1. 更新 tool 注册 schema（MCP/adapter 层）。
2. adapter 层禁止将 payload 归一成 {}。
3. handler 增加 switch(action) 骨架及错误返回。
4. 单测覆盖契约负例。
6. 错误码（初版）
- MODELCFG_ERR_MISSING_ACTION
- MODELCFG_ERR_UNKNOWN_ACTION
- MODELCFG_ERR_UNKNOWN_FIELD
- MODELCFG_ERR_INVALID_PAYLOAD
7. 测试清单
- 无 action 报错
- 非法 action 报错
- unknown field 报错
- payload 原样到达 handler
8. 验收标准
- 能看到 handler 收到完整 payload（非 {}）。
- 所有契约测试通过。
9. 风险与回滚
- 风险：严格校验导致旧调用方失败。
- 回滚：仅回滚 schema strict 模式，保留透传修复。
